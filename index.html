Rclone Investigacion 2026

Esta página presenta una configuración personal de rclone, una herramienta de código abierto para gestionar y sincronizar archivos.

Finalidad

La configuración permite sincronizar una carpeta de trabajo de Google Drive con un computador Ubuntu. Se utiliza para mantener actualizados archivos de investigación y documentos de trabajo entre dispositivos autorizados por el propietario de la cuenta.

Acceso a Google Drive

El acceso se solicita mediante OAuth de Google. La sincronización la realiza rclone en el computador configurado; este sitio web informativo no solicita credenciales, no aloja archivos sincronizados y no ejecuta tareas de sincronización.
