Política de privacidad

Aplicación: Rclone Investigacion 2026

Última actualización: 27 de octubre de 2026

1. Propósito

Esta configuración personal utiliza rclone para sincronizar archivos entre una cuenta de Google Drive autorizada y un computador local. No es un servicio público de almacenamiento ni una aplicación ofrecida a terceros.

2. Información a la que se accede

Con la autorización expresa del titular de la cuenta, rclone puede consultar, descargar, crear, modificar y eliminar archivos de Google Drive de acuerdo con los permisos OAuth concedidos y la configuración de sincronización. El permiso solicitado puede conceder acceso amplio al Drive, aunque la tarea local esté configurada para una carpeta específica.

3. Uso y almacenamiento de información

La transferencia de archivos se realiza entre Google Drive y el equipo configurado mediante rclone. Los archivos sincronizados se almacenan en las ubicaciones indicadas por el titular; los datos de autorización se almacenan en la configuración local de rclone. Esta página web no recibe ni almacena copias de los archivos sincronizados o de las credenciales OAuth.

4. Compartición de información

Esta configuración no está diseñada para vender datos personales ni para compartir archivos con anunciantes. Se utilizan la API de Google Drive y la infraestructura necesaria para prestar el servicio. El alojamiento de esta página informativa está a cargo de GitHub Pages, sujeto a sus propias prácticas de privacidad.

5. Control y revocación

El titular puede detener la sincronización en su computador, eliminar las copias locales que correspondan y revocar el acceso de la aplicación desde la configuración de seguridad de su cuenta de Google. La revocación impide nuevas operaciones autorizadas, pero no elimina automáticamente copias de archivos ya sincronizadas.

6. Contacto

Las consultas relacionadas con esta configuración pueden dirigirse a través de GitHub Issues del repositorio.
